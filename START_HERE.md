# SAAYA v7 — start here

This is the current **19-occupation SAAYA** version. Read `SAAYA_V7_RELEASE.md` for features and limitations and `OCCUPATION_RESEARCH.md` for the underlying research.

On Windows: extract ZIP → `SAAYA-MOBILE` → double-click `START-SAAYA.bat`. The site opens at `http://localhost:3010/welcome`. Finish the role setup and choose an address for regional weather/model lookup. Select `Fisher`, `Marine / offshore worker`, `Cargo ship crew`, `Construction worker`, or any other occupation to see a distinct checklist and role-specific suggestions.

The app is a **source-code development build**; it does not include signed iOS/Android apps, verified field observations or certified occupational limits.
